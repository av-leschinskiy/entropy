# Отдельное хранилище статистики символьной тренировки

## Цель

Вынести адаптивную статистику Typing Trainer из общих настроек приложения в
самостоятельный JSON-файл. Это не даёт часто меняющейся таблице ошибок
раздувать `app_settings.json` и позволяет пользователю сбросить или сохранить
её отдельно.

## Формат и путь

Файл располагается по пути:

```text
~/.config/entropy/typing_trainer_symbol_stats.json
```

Он хранит версию формата и таблицу `символ -> { attempts, errors }`. Таблица
остаётся глобальной: не делится по устройству, раскладке или слою. Новый модуль
хранилища отвечает за построение пути, чтение и запись этого JSON; модель
тренажёра получает уже загруженную таблицу.

## Поведение

- При старте Entropy читает отдельный файл. Отсутствующий или повреждённый файл
  означает пустую статистику и не мешает запуску приложения.
- После завершения упражнения актуальная таблица записывается в этот файл.
- `app_settings.json` больше не записывает статистику символов.
- Данные старого поля в `app_settings.json` намеренно не мигрируются и не
  удаляются: пользователь выбрал начать новую статистику, а старый файл
  остаётся совместимым с предыдущей версией Entropy.
- Ошибка чтения или записи логируется и не прерывает тренировку. До следующего
  успешного сохранения статистика продолжает жить в памяти текущего процесса.

## Проверка

Автоматические тесты проверяют round-trip отдельного файла, отсутствие файла и
некорректный JSON. Существующие тесты генератора продолжают проверять, что
загруженная статистика повышает вероятность ошибочных символов.
